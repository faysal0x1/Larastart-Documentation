# Contact

Have a question, feature request, or found an issue? Reach out via GitHub.

## Support channels

- Issues: open a ticket at `https://github.com/faysal0x1/larastart/issues`
- Pull Requests: improvements are welcome at `https://github.com/faysal0x1/larastart/pulls`

## Reporting issues

Please include:

- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, PHP, Laravel, Node)
- Screenshots or logs where applicable

## Security

If you discover a security vulnerability, please avoid public issues. Instead, open a private report following GitHub’s security reporting guidelines.
