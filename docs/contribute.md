# How to Contribute

Contributions are welcome! Follow the steps below to get started.

## Development setup

1. Fork and clone the repo
2. Install dependencies: `npm ci`
3. Run docs locally: `npm run docs:dev`

## Making changes

- Create a feature branch
- Keep edits focused and documented
- Update or add docs as needed

## Commit and PR

- Follow conventional commits if possible
- Open a Pull Request with a clear description
- Link related issues
